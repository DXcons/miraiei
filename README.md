# 未来栄株式会社 図面管理システム

未来栄株式会社向けWebアプリです。ログイン認証と図面データはFirebase（Authentication + Firestore）を
使った実データで動作します。図面の新規作成・編集・保存機能は開発中のプレースホルダーです（[注意事項](#注意事項)参照）。

## 画面構成

| ファイル | 画面 |
|---|---|
| [login.html](login.html) | ログイン画面（Firebase Authに登録済みのメールアドレス・パスワードでログイン） |
| [home.html](home.html) | ログイン後のホーム（「過去の図面をさがす」「新しい図面をつくる」「図面を保存する」） |
| [search.html](search.html) | 図面検索画面（屋外/室内、樹脂/金属、部品名、寸法での絞り込み＋該当件数表示） |
| [detail.html](detail.html) | 図面詳細画面（検索結果クリックで遷移。図面情報＋「必要な材料」一覧を表形式で表示） |
| [new.html](new.html) | 新規作成画面（「過去の図面をコピーして編集する」→検索ポップアップ／「ゼロから作る」） |
| [edit.html](edit.html) | 図面編集画面（プレースホルダー。実際の作図UIは未実装） |
| [pdf-new.html](pdf-new.html) | PDF図面の保存画面（客先・図面作成日・品名を付けてPDFを登録。複数ファイル同時可） |
| [pdf-list.html](pdf-list.html) | 保存済みPDF図面の検索・閲覧・ダウンロード・削除 |
| [seed.html](seed.html) | 初回データ投入用（管理者がセットアップ時に1回だけ使う。投入後は削除する） |

## セットアップ（Firebase連携）

1. [Firebaseコンソール](https://console.firebase.google.com/) で新規プロジェクトを作成する。
2. **構築 > Authentication** を開き、「始める」→ ログイン方法で **メール/パスワード** を有効化する。
   （本アプリにサインアップ画面はないため、利用者アカウントは次の手順でしか作られません）
3. **Authentication > Users** タブから「ユーザーを追加」で、利用者ごとにメールアドレス／パスワードを登録する。
4. **構築 > Firestore Database** を開き、「データベースの作成」（本番環境モードで作成）。
5. Firestoreの **ルール** タブを開き、いったん以下の内容に置き換えて「公開」する（データ投入のため一時的に書き込みを許可）。
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /drawings/{drawingId} {
         allow read, write: if request.auth != null;
       }
     }
   }
   ```
6. **プロジェクトの設定(歯車アイコン) > 全般** の「マイアプリ」でウェブアプリを追加し、表示された`firebaseConfig`の値を
   [`js/firebase-config.js`](js/firebase-config.js) に貼り付ける。
7. 変更をコミットしてGitHubへpush（GitHub Pagesに反映されるまで数分待つ）。
8. 公開されたサイトで手順3のアカウントでログインし、`seed.html` を開いて「ダミーデータ12件を投入する」を実行する。
9. 投入完了後、`seed.html` を削除し、Firestoreのルールを [`firebase/firestore.rules`](firebase/firestore.rules) の内容
   （読み取り専用）に戻して再度「公開」する。

`js/firebase-config.js` の値はクライアント側に公開される前提の識別子です。データの保護はFirestoreの
セキュリティルール（`drawings`はログイン済みユーザーのみ閲覧可・書き込み不可）で行っているため、
リポジトリに含めても問題ありません。

## 使い方

`login.html` をブラウザで開いてください（`index.html` からも遷移します）。
セットアップ手順3で作成したメールアドレス・パスワードでログインします。
ローカルファイルとして開く場合も動作しますが、Firebase接続のため通信環境が必要です。

## 検索条件の項目

- 設置場所：屋外／室内（単一選択）
- 材質：樹脂／金属（複数選択）
- 部品名：プーリー／ローラー／ベルト／調芯／その他（複数選択）
- ロールの寸法：直径・長さ（それぞれ下限〜上限の範囲指定）
- コンベヤの寸法：幅・長さ（それぞれ下限〜上限の範囲指定）

検索条件の変更に応じて「該当する図面の数」がリアルタイムに更新されます。
図面データはFirestoreの `drawings` コレクションから取得します（内容は [`seed.html`](seed.html) 参照、値はダミーです）。

## PDF図面の保存（図面を保存する）

ホームの「図面を保存する」から、PDFの図面を **客先／図面作成日／品名** とあわせてFirestoreに登録します。

### 保存のしくみ

Firebase Storage（ファイル保管庫）は有料のBlazeプランが必須のため、本アプリでは使いません。
代わりに、PDFをBase64文字列に変換して **Firestoreに分割して保存** しています（[`js/pdf-store.js`](js/pdf-store.js)）。
これにより無料のSparkプランのまま、クレジットカード登録なしで運用できます。

```
pdfDrawings/{id}                … 客先・図面作成日・品名・ファイル名・サイズなど（検索用）
pdfDrawings/{id}/chunks/{nnnn}  … PDF本体を50万文字ずつに分割したBase64データ
```

Firestoreは1ドキュメント約1MBが上限のため50万文字ずつに分割し、読み出し時に結合して元のPDFに戻します。

### 制限と目安

| 項目 | 値 | 備考 |
|---|---|---|
| 1ファイルの上限 | 20MB | 超えるファイルは選択時に弾かれます |
| 保存できる合計容量 | 約1GB（Firestore無料枠） | Base64化で約1.34倍になるため、実PDFで約750MB相当 |
| 1日の書き込み回数 | 20,000回（無料枠） | 0.5MBごとに1回。3MBのPDFなら1件あたり約8回 |

容量が足りなくなった場合は、Firebaseを**Blazeプラン**に切り替えてFirebase Storageへ移す方法が
あります（この構成からの移行は、保存先を差し替えるだけで済むように分離してあります）。

### 客先一覧CSV

「客先」の選択欄は [`data/customers.csv`](data/customers.csv) を読み込んで作られます。
このファイルをGitHub上で差し替えれば、選択肢が更新されます。

- 1列目に客先名を並べるだけの単純なCSVでかまいません。
- 1行目に「客先名」「取引先」「会社名」などの見出しがある場合は、その列を自動で使います。
- 文字コードはUTF-8とShift_JISの両方に対応しています（Excelで「CSV」として保存したファイルもそのまま読めます）。

画面上の「CSVを読み込む」ボタンから手元のCSVを選ぶこともできます。この場合はそのブラウザにだけ
保存され、「元に戻す」で `data/customers.csv` の内容に戻ります。

一覧にない客先は、選択欄の「＋ 一覧にない客先を直接入力する」を選ぶと自由入力できます。

### 品名の入力補完

「品名」欄は自由入力ですが、[`data/products.csv`](data/products.csv) に載っている品名を入力候補として
表示します（クリックすると候補が出るプルダウン形式）。候補は過去の図面（CAM'S様の図面例など）に
実際に記載されていた品名をもとにした初期リストです。候補にない品名もそのまま入力できます。
候補を増やしたいときは `data/products.csv` に1行ずつ品名を追記してください。

### セキュリティルールの更新

この機能を使うには、Firestoreのルールに `pdfDrawings` の設定が必要です。
[`firebase/firestore.rules`](firebase/firestore.rules) の内容をFirebaseコンソールの
**Firestore Database > ルール** に貼り付けて「公開」してください。

## 注意事項

- ログイン認証・図面データの閲覧・PDF図面の保存はFirebaseによる実データですが、図面の作図・編集機能は
  引き続きプレースホルダー（[edit.html](edit.html)）であり、実際の作図は行われません。
- ログイン状態はFirebase Authのセッション（ブラウザのローカルストレージ）で管理されます。
- PDF図面の保存・閲覧はFirestoreへの通信が必要です。ローカルファイル（`file://`）で開いた場合、
  `data/customers.csv` の自動読み込みだけはブラウザの制限で動きません（画面上の「CSVを読み込む」は使えます）。
